# OTP Generator

A simple Python script that generates numeric One-Time Passwords (OTPs).

## Features

- Generates random numeric OTPs
- Supports OTP lengths from **6 to 10** digits
- Simple command-line interface

## Requirements

- Python 3.x

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/ankushminhas80366-tech/OTP_Generator.git
   cd OTP_Generator
   ```

2. Run the script:
   ```bash
   python Main.py
   ```

3. Enter the desired OTP length (between 6 and 10) when prompted.

## Example

```
Enter the length of OTP you want: 6
Generating OTP:
Your OTP is: 384729
```

## Notes

- OTP length must be between 6 and 10 (inclusive).
- The generator uses only numeric digits (0–9).
